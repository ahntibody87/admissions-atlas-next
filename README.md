# ATAA Next — 디자인 비교판

기존 ATAA를 유지한 채 리뉴얼 방향을 비교하는 별도 프로젝트입니다. 공개된 대학 목록과 로컬 Pretendard 글꼴을 사용하며 외부 스크립트, 계정, DB, 개인정보 수집은 없습니다.

- A: 깊이 있는 지도
- B: 명료한 리서치
- C: 담백한 아틀라스

`npm run dev` 후 http://127.0.0.1:4173 을 엽니다. `?theme=b#analysis`처럼 원하는 시안과 화면을 바로 열 수 있습니다.

`npm run check`로 JavaScript 구문을 확인합니다. 별도 빌드 없이 GitHub Pages에서 게시할 수 있습니다.

`DESIGN.md`에 디자인 기준·관찰·다음 피드백 항목을 기록했습니다. 현재 대학 상세와 계산 도구는 기존 운영 사이트에서 열립니다. 04 원서 접수 시뮬레이션은 준비 중입니다.

지도 그래픽은 이 프로젝트의 코드로 생성한 개념도입니다. 참고 사이트의 이미지·영상·소스 코드는 복제하지 않았습니다. Pretendard 폰트 라이선스는 `assets/Pretendard-LICENSE.txt`에 있습니다.
