# ATAA · 입시 정보

흰색·파랑과 Pretendard를 사용하는 별도 리뉴얼 사이트입니다.

- 저장소: https://github.com/ahntibody87/admissions-atlas-next
- 사이트: https://ahntibody87.github.io/admissions-atlas-next/
- 기존 운영 사이트 및 다른 저장소는 변경하지 않습니다.

## 실행

`npm run dev` → http://127.0.0.1:4173 (`PORT` 환경변수 지원).
`npm run check` → app.js, data.js, 로컬 서버 JavaScript 구문 검사.
별도 빌드 없이 main 브랜치 루트에서 GitHub Pages로 게시합니다.

## 동작

중앙의 실사 영상 창에서 한 번의 스크롤, 클릭/탭, 위로 쓸기, Enter/Space/PageDown/아래 화살표로 입장합니다. 영상 창을 1.05초 동안 화면 전체로 확대하고 잠시 유지한 뒤 메뉴로 이동합니다. 반복 입력은 무시합니다. 내부 화면은 자연 스크롤입니다. `#intro`로 입장 화면에 돌아올 수 있고 각 메뉴는 해시 주소로 바로 열립니다.

영상은 음소거·인라인 재생이며 재생/일시정지 버튼을 제공합니다. 자동재생 실패 시 수동 재생 안내를 표시합니다. 영상 로딩 실패 시 표지를 유지하고 입장할 수 있습니다. 동작 줄이기를 설정한 경우 자동재생과 확대 애니메이션을 생략합니다. 백그라운드 탭에서는 영상을 정지합니다.

## 자료와 범위

대학 목록 29개와 캠퍼스·모집단위 수는 기존 공개 목록의 스냅샷을 보존했습니다. 모집단위 수는 제공 자료의 비교 범위이며 대학 전체 학과 수와 다를 수 있습니다. 원자료는 기존 ATAA의 2027–2028학년도 전형 분석에서 확인합니다. 자료 확인일 표시는 기존 자료 기준을 유지합니다. 대학 상세·권장과목·내신 및 정시 도구는 기존 운영 사이트의 실제 주소로 새 창 연결합니다. 04 원서 접수 시뮬레이션은 준비 중이며 저장·합격예측·임의 합격선을 제공하지 않습니다. 로그인·DB·Vercel은 사용하지 않습니다.

## 영상과 글꼴

`assets/MEDIA.md`에 영상 출처·이용 조건·인코딩을 기록했습니다. 캠퍼스는 분위기용 해외 실사 촬영 영상이며 목록의 특정 대학을 나타내거나 추천·제휴를 의미하지 않습니다. 레퍼런스 사이트의 영상·이미지·소스는 복제하지 않았습니다. Pretendard 라이선스는 `assets/Pretendard-LICENSE.txt`에 있습니다.

복구 과정 및 실제 검증 결과는 `PROGRESS.md`를 확인하세요.
