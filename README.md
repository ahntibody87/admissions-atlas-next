# ATAA · 입시 정보

흰색·파랑과 Pretendard를 사용하는 별도 리뉴얼 사이트입니다.

- 저장소: https://github.com/ahntibody87/admissions-atlas-next
- 사이트: https://ahntibody87.github.io/admissions-atlas-next/
- 기존 운영 사이트 및 다른 저장소는 변경하지 않습니다.

## 실행

`npm run dev` → http://127.0.0.1:4173 (`PORT` 환경변수 지원).
`npm run check` → app.js, data.js, 로컬 서버 JavaScript 구문 검사.
별도 빌드 없이 main 브랜치 루트에서 GitHub Pages로 게시합니다.

## 동작

입장 화면에서 첫 스크롤·클릭·탭·위로 쓸기·키보드 입력은 세로 영상 창을 1.05초 동안 전체 화면으로 확대합니다. 확대 후 영상 재생을 그대로 유지합니다. 다음 스크롤·위로 쓸기 또는 메뉴 보기 버튼으로 영상 아래 홈에 부드럽게 내려갑니다. 이 과정에서 영상 요소를 교체하지 않고 확대 시 내비게이션을 표시하고 스크롤에 따라 흰 배경을 강화합니다. 반복 입력과 첫 제스처의 관성 입력으로 두 단계가 한꺼번에 실행되지 않도록 합니다. `#intro`는 입장 화면, `#home`은 홈 바로 가기입니다.

영상은 음소거·인라인 재생이며 작은 재생/일시정지 아이콘을 제공합니다. 입장 화면 오른쪽 아래는 플랫폼 소개이며, 소개 카드는 두 문단으로 구성합니다. 자동재생 실패 시 수동 재생 안내를 표시합니다. 영상 로딩 실패 시 표지를 유지하고 입장할 수 있습니다. 동작 줄이기를 설정한 경우 자동재생과 확대·스크롤 애니메이션을 생략하되 두 단계 입장은 유지합니다. 백그라운드 탭에서는 영상을 정지합니다.

## 자료와 범위

대학 목록 29개와 캠퍼스·모집단위 수는 기존 공개 목록의 스냅샷을 보존했습니다. 모집단위 수는 제공 자료의 비교 범위이며 대학 전체 학과 수와 다를 수 있습니다. 원자료는 기존 ATAA의 2027–2028학년도 전형 분석에서 확인합니다. 자료 확인일 표시는 기존 자료 기준을 유지합니다. 대학 상세·권장과목·내신 및 정시 도구는 기존 운영 사이트의 실제 주소로 새 창 연결합니다. 04 원서 접수 시뮬레이션은 준비 중이며 저장·합격예측·임의 합격선을 제공하지 않습니다. 로그인·DB·Vercel은 사용하지 않습니다.

## 영상과 글꼴

`assets/MEDIA.md`에 영상 출처·이용 조건·인코딩을 기록했습니다. 캠퍼스는 분위기용 해외 실사 촬영 영상이며 목록의 특정 대학을 나타내거나 추천·제휴를 의미하지 않습니다. 레퍼런스 사이트의 영상·이미지·소스는 복제하지 않았습니다. Pretendard 라이선스는 `assets/Pretendard-LICENSE.txt`에 있습니다.

복구 과정 및 실제 검증 결과는 `PROGRESS.md`를 확인하세요.

## 공통 레이아웃과 아이콘

홈·내부 페이지·내비게이션·하단은 동일한 최대 폭 1440px과 좌우 여백을 공유합니다. PC 1280×720의 홈은 최근 반영과 LAST UPDATED까지 한 화면에 배치하며 모바일은 자연스럽게 이어서 스크롤합니다. 최근 반영 항목과 날짜는 기존 운영 홈을 보존하고, LAST UPDATED는 리뉴얼 사이트의 마지막 수정일입니다. 나침반은 직접 작성한 SVG와 PNG/ICO 북마크·홈 화면 아이콘을 함께 제공합니다. 실사 캠퍼스 표지를 흐린 배경으로 재사용합니다.

### 2026-11-08 화면 보정

확대 영상 위에서도 내비게이션을 즉시 사용할 수 있으며, 흰 배경 불투명도는 0.56에서 홈의 1까지 스크롤 비율에 따라 증가합니다. 홈은 PC 화면 높이에 맞춰 제목·메뉴·최근 반영 간격과 크기를 조정합니다. 소개 문구는 학생 맞춤형 진학 지도 플랫폼이며 별도 기존 사이트 안내 줄은 제거했습니다.

### 입장 및 내부 카드 개편

영상 위 ATAA 대신 학생 맞춤형 / 진학 지도 플랫폼 두 줄 제목을 중앙에 배치했습니다. 입장 전 로고는 공통 header-inner로 정렬하여 입장 후 로고와 좌표·크기·SVG 색상을 공유하며, 오른쪽 영문명도 같은 좌우 여백을 사용합니다. 하단 안내·플랫폼 소개 위치를 유지하면서 글씨와 입장 버튼을 키웠습니다.

전형 분석은 기존 운영 사이트의 그라데이션 카드·캠퍼스와 학년도·대학 약칭·설명·하단 링크 및 안내 문단 구성을 보존했습니다. 목표 설계와 입시 자료도 같은 카드 스타일을 사용합니다. 원본 대학 데이터와 링크를 유지하며 04는 준비 중입니다.
